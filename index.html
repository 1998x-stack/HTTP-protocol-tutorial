如何使用这套课程

无需安装任何依赖：直接在浏览器中打开本页，或打开任意章节的 HTML 文件即可阅读。每章正文左侧是 28 章目录，底部提供「上一章 / 目录 / 下一章」导航。建议先读第 1–3 章建立报文与 URL 的直观印象，再按阶段推进；遇到缓存、认证、CORS 这类工程概念时，可对照示例报文逐行理解。
